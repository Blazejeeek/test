⚡ Szybko

Każda zmiana w repozytorium jest wdrażana bez ręcznego logowania na serwer.

🔒 Bezpiecznie

Prywatne repozytorium, połączenie HTTPS i dostęp przez GitHub App.

🏠 Własny serwer

Wszystko działa na domowym serwerze z Coolify, bez opłat za hosting.

Jak to działa

  1. Zmiana w kodzie – edytujesz pliki i robisz git push.
  2. GitHub – wysyła powiadomienie (webhook) do Coolify.
  3. Coolify – pobiera kod i buduje nową wersję.
  4. Gotowe – nowa wersja jest dostępna pod strona.devgs.top.
